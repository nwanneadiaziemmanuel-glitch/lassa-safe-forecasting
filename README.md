# Safe, Uncertainty-Aware Forecasting for Sparse Lassa Outbreaks

A trustworthy-AI research project evaluating whether lightweight machine-learning forecasting remains reliable when Lassa fever surveillance is sparse, seasonal, highly variable and vulnerable to degraded signals.

**Project 1 of a portfolio on Trustworthy AI for Biomedical Intelligence and Biosecurity.**

## Research question

Can a lightweight machine-learning model forecast short-horizon weekly Lassa fever surveillance signals while making uncertainty, peak-event performance, robustness and reproducibility explicit?

## Why this project matters

Outbreak forecasting should not be evaluated only by average prediction error. A trustworthy system should also be examined for:

- performance during high-intensity outbreak weeks;
- uncertainty coverage;
- sensitivity to missing recent surveillance information;
- synthetic-data fidelity;
- temporal generalisation; and
- reproducibility of the reported analysis.

## Current V1.0 core study design

- **Target:** weekly confirmed Lassa fever cases.
- **Data:** weekly aggregate surveillance series derived from NCDC epidemiological reports.
- **Coverage:** 30 December 2019–10 November 2025.
- **Primary model:** shallow Huber-loss Gradient Boosting.
- **Features:** historical lags, shifted rolling means and epidemiological-week sine/cosine terms.
- **Validation:** leakage-controlled expanding year-based temporal holdout.
- **Horizons:** 1–4 weeks ahead.
- **Evaluation:** MAE and RMSE for the reproducible core forecast analysis.

## Reproduce the V1.0 core analysis

```bash
python -m pip install -r requirements.txt
python -m pytest -q
python -m src.run_analysis
```

The reproducible outputs are written to `results/v1_1_core/`.

## Historical V1.0 analytical archive

The original/frozen V1 analysis is preserved rather than silently overwritten:

```text
results/archive_v1/
figures/archive_v1/
```

The archive contains the original model-comparison, augmentation, uncertainty, robustness, failure-analysis and synthetic-fidelity outputs. It is clearly separated because those outputs were produced by an earlier analytical pipeline and are not all regenerated by the V1.1 core runner.

See `docs/result_provenance.md` for the exact status of each result group.

## Key trustworthy-AI lessons from the project

The historical analysis motivated the corrected V1.0 release and showed that:

1. high-intensity weeks can be substantially harder to forecast than ordinary weeks;
2. nominal 95% uncertainty intervals can under-cover;
3. simple synthetic augmentation is not consistently beneficial;
4. synthetic procedures can fail to preserve important tail behaviour; and
5. missing recent surveillance information can materially degrade forecasts.

These findings are presented as methodological evidence and limitations, not as evidence that the model is ready for operational deployment.

## Safety and ethics

This is a research prototype, not an operational outbreak-response decision system. Synthetic observations are clearly treated as synthetic and should not be interpreted as real surveillance observations.

The project does not claim that its forecasts should be used directly for clinical or public-health decisions without further validation.
